Install in four taps

  1. Tap Download above. Chrome may ask whether to keep the file. Keep it.
  2. Open the downloaded file from the notification, or from Files → Downloads.
  3. If Android says the phone isn't allowed to install from this source, tap Settings, switch it on for Chrome (or Files), then go back.
  4. Tap Install, then Open. Sign in with your FactoryLM account.

Google Play Protect may show a “scan app” prompt the first time because this build isn't from the Play Store. Choose Scan or Install anyway; the app is signed by FactoryLM (fingerprint below).
