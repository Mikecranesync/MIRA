you can actually have problems with pf525 if the load is too great on startup, and it will limit your output with a sustained HZ. essentially looking like a bad motor/drive.

you might try looking into parameter A495. I've seen erratic operation from 525 and 4m drives when the load was too much to allow it to run properly, but not restricted enough to cause an overload condition.

That and possibly upping the current limit to see what happens with it (A484-A485)

Double check that your S1 and S2 jumper is correctly terminated. If you clamped onto the insulation it will look like it is installed but there is no connection. That input is a base block, it disables the transistors.

Look at b006, bit 5. If it’s high, the S1/2 circuit is active. If not, it is not continuous.
