What do you mean by not connecting to the network?
I would check the basics first. Is the "ENET" light or the "LINK" light on or flashing?
A step further would be to hook up a laptop to the network switch and see if you can ping the drive. After that you should be able to see it on rslinx.
If you have access to the program, you can see if the plc's talking to the drive, and also double check that the drive electronic keying is set to "Compatible Module" or "Disable Keying". If it is set to "Exact match" then the drive is not going to talk because the firmware is different.
