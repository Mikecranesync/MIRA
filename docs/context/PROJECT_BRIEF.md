# MIRA — Project Brief

**Updated:** September 5, 2026
**Direction:** [NORTH_STAR.md](../../NORTH_STAR.md)
**Delivery:** [Unified plan](../product/2026-09-05-sellable-app-alignment.md), [MIRA #3586](https://github.com/Mikecranesync/MIRA/issues/3586).

FactoryLM is the product; MIRA is its assistant. Improve the existing mobile app so it opens into a clean conversation. Group retained capabilities into Chat, Projects, Knowledge, Work, and Settings through a menu/sidebar, not five mandatory phone tabs. Preserve accounts, equipment, notebooks, documents, evidence, integrations, and native behavior.

The first customer proof is a new user asking a question, adding their own photo/manual, establishing required equipment context, receiving cited help or a useful clarification, following up, saving a finding, and reopening the same work. General help before equipment selection must not bypass asset-specific confirmation, approved retrieval, or safety.

## Current sequence

1. Inventory current mobile features, build, routes, data, flags, and working/broken paths.
2. Reuse existing ChatV2 for app-level chat/home/history and quiet navigation.
3. Keep existing features and records reachable; prove the complete journey and tenant isolation.
4. Verify supported-device behavior, onboarding, support, purchase/access, cost, and an approved paid pilot.

`Mikecranesync/MIRA` owns the customer experience. `Mikecranesync/factorylm` contributes reusable supporting capabilities. Slack/Foreman is Mike's internal command center. Work maps to an app outcome or an existing security/reliability obligation.
