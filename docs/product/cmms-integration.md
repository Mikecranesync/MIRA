# CMMS Integration

MIRA works without a CMMS.

> **Status:** No connector is Working. MaintainX adapter code exists and is In testing.

## Connector status

| Platform | Status | Notes |
|---|---|---|
| MaintainX | In testing | Adapter code exists; not proven. Email support@factorylm.com |

Connectors without working code are not listed.

## Connecting

There is no self-serve Settings → CMMS → Connect flow. Email [support@factorylm.com](mailto:support@factorylm.com) to request setup for a connector that is In testing.

## Safety and data handling

- **No automated write-backs.** MIRA does not automatically write, sync, or push to a CMMS.
- **Per-tenant isolation.** Plant data is not shared with other FactoryLM tenants.
- **Audit log.** CMMS writes, when they exist, are logged against the MIRA user who approved them.

## Frequently asked questions

**Q: Can MIRA work without any CMMS?**
A: Yes. Chat and diagnostic features work without a CMMS.

**Q: What if my CMMS doesn't have a public API?**
A: Contact support.
