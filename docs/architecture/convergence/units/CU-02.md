## Canonical implementation

- `tools/gen_container_map.py` — parses the root `docker-compose.yml` `include:` set +
  `docker-compose.override.yml` (dev) and `docker-compose.saas.yml` (prod); rewrites the
  `CLAUDE.md` section between `BEGIN/END GENERATED container-map` markers. Modes: print /
  `--write` / `--check` (exit 1 on drift). Profile-gated services are annotated
  `*(profile: x)*` with a footnote (they don't start on a plain `up`); both table headers
  carry the env-defaults caveat. Style-matched to `tools/check_env_drift.py`.
- Root `CLAUDE.md` Container Map = the generated two-table section (Dev + Prod, staging as a
  pointer), each table header naming its source compose file — the environment-mixing that
  caused D-2 is now impossible to do silently.
- `docs/specs/hub-mobile-spec.md` — supersession header → ADR-0034
  (`docs/adr/0034-native-mobile-static-capacitor-client.md`) + mobile PRD
  (`docs/prd/2026-08-13-native-mobile-app-prd.md`); the OUT-of-scope line annotated. The
  responsive-layout contract remains authoritative for the Hub web UI (the PRD cites it).
- Root `CLAUDE.md` sidecar lines (repo map + Deferred table) → "removed from prod
  2026-05-20; directory deletion tracked separately (Gate 11)".
