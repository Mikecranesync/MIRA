## Detailed Evidence & Impact  

### 1. `_urls_in` misses leading‑whitespace URLs (high)  
```python
# origins.py:36‑42 (new)
if isinstance(n, ast.Constant) and isinstance(n.value, str) \
   and n.value.lower().startswith(("http://", "https://"))
```
*Bug*: `n.value.lower().startswith` does **not** ignore leading spaces.  
*Impact*: A manifest constant like `"   HTTPS://EXAMPLE.COM/feed.xml"` is silently ignored. The policy‑consistency test then sees no origin, allowing an unclassified (private) URL to slip through without a provenance policy entry – exactly the case‑sensitivity gap the round is meant to close.

### 2. `_urls_in` ignores dynamic strings (high)  
Only `ast.Constant` nodes are visited.  `ast.JoinedStr` (f‑strings) and `ast.BinOp` (concatenation) are excluded.  
*Impact*: Real‑world manifests frequently construct URLs programmatically (e.g. `f"https://{HOST}/feed.xml"`). Those origins remain undiscovered, breaking the “origin discovery” contract and leaving the gate effectively open for unclassified URLs.

### 3. Default‑port stripping limited to HTTP/HTTPS (high)  
```python
_DEFAULT_PORTS = {"http": 80, "https": 443}
```
*Bug*: Schemes such as `ftp`, `sftp`, or custom `myproto` that have well‑known default ports are **not** canonicalised.  
*Impact*: `ftp://example.com:21/file` and `ftp://example.com/file` are stored as distinct keys, violating the “exact‑match UNIQUE index” guarantee and allowing duplicate rows for the same logical document.

### 4. Tenant‑ID guard changes historic semantics (high)  
```python
if not isinstance(tenant_id, str) or not tenant_id.strip():
    logger.warning(...)
    return set()
```
*Regression*: Pre‑change, an empty `tenant_id` caused the query to **omit** the tenant predicate, effectively scanning *all* tenants.  Existing callers (e.g. the ledger probe in `ingest/ingest.py`) rely on this to detect cross‑tenant duplicates.  
*Impact*: After the guard, such callers receive an empty result set, causing the ledger to think a URL is “not ingested” and subsequently re‑write it under a different tenant, breaking tenant isolation and potentially leaking data across tenants.

### 5. Missing‑ruling‑treated‑as‑PASS bug (high)  
`adjudication_verdict_strict` validates shape but then calls `adjudication_verdict(parse_rulings(...), prior)`.  
*Bug*: `adjudication_verdict` only looks at the rulings it receives; any high‑severity finding **without** a ruling is treated as a PASS.  
*Impact*: An adjudicator could simply omit rulings for high findings, causing the system to accept the PR (PASS) despite an unresolved high defect. This violates the “bijection” contract and opens a denial‑of‑service vector for the reviewer (they cannot force a BLOCK without explicitly ruling).

### 6. `.log` added to documentation suffixes (high)  
```python
_DOC_SUFFIXES = (".md", ".markdown", ".rst", ".txt", ".log")
```
*Bug*: Log files are operational artefacts, not documentation. Their presence now flips PR kind to “documentation‑only”.  
*Impact*: Reviewers are briefed to apply documentation‑only expectations (e.g., “policy‑consistency” checks) while the PR may actually contain runtime‑log changes that affect code behaviour. This mis‑classification can hide genuine code defects.

### 7. Colon‑only port left in canonical URL (medium)  
`canonical_source_url("https://example.com:/x")` → `"https://example.com:/x"` (colon retained).  
*Impact*: The resulting URL is malformed per RFC 3986, yet the system stores it unchanged. Downstream components that later parse the URL may raise errors or fail to match, leading to inconsistent look‑ups.

### 8. Evidence‑artifact drop may hide moved code (medium)  
`drop_evidence_artifacts` treats any file that *was* in the evidence directory as an artifact, even if it is moved into the directory via a rename.  
*Scenario*: A developer refactors `src/util.py` → `docs/architecture/convergence/units/evidence/util.py`. The diff shows a rename; the function drops the target path, removing the file from review.  
*Impact*: Code changes can be silently omitted from the reviewer’s view, violating the “no silent‑scope” guarantee.

### 9. Indented fences not stripped (low)  
The fence‑stripper does not recognise fences that are indented (four spaces) – a style sometimes used in Markdown.  
*Impact*: A `## VERDICT` line inside such a fence could be erroneously interpreted as a second verdict section, causing the shape validator to reject a valid review (UNKNOWN) and waste a round.

### 10. Fragment percent‑escape case‑folding (low)  
Upper‑casing `%ab` in the fragment changes the literal fragment identifier. Some downstream tools treat fragments case‑sensitively, so a stored URL may no longer resolve to the same anchor.  
*Impact*: Minor but can break dedup for URLs that rely on fragment anchors.
