## FINDINGS
- **[severity: high] Windows case‑insensitive path containment bypass in `_validated_local_path`** – The containment guard used by the ingest pipeline appears to rely on a simple case‑sensitive prefix check of the resolved absolute path against the allowed base directory. On case‑insensitive file systems (e.g., Windows), a path that differs only in letter case can evade the check, allowing an attacker to read files outside `INGEST_LOCAL_ALLOWED_DIR`. The new tests `test_containment_gate_refuses_a_path_outside_the_base_on_every_platform` only verify exact‑case matches and sibling directories, leaving the case‑variation scenario uncovered:

  ```python
  assert _validated_local_path((base / "doc.pdf").resolve().as_uri())
      == (base / "doc.pdf").resolve()
  ...
  assert _validated_local_path(stray.resolve().as_uri()) is None
  ...
  assert _validated_local_path((sibling / "doc.pdf").resolve().as_uri()) is None
  ```

  These assertions exercise only straightforward absolute paths; they do **not** test a path such as `C:\INBOX\..\EVIL\file.pdf` (or the same path with different casing). Consequently the guard could either falsely reject legitimate files or, worse, allow out‑of‑scope reads on Windows, breaking tenant isolation and the security boundary.

- **[severity: medium] Missing handling of IPv6 default ports with leading zeros in `store.canonical_source_url`** – The canonicalisation logic removes explicit default ports for HTTP/HTTPS, as verified for IPv4 (`"https://example.com:0443/x"` → `"https://example.com/x"`) and for IPv6 without leading zeros (`"https://[2001:DB8::1]:443/A"` → `"https://[2001:db8::1]/A"`). However, the test suite does **not** include an IPv6 case with leading zeros (e.g., `"https://[2001:DB8::1]:0443/x"`). If the implementation only strips the port when the literal string equals `"443"` (or after integer conversion without handling the leading‑zero form), such a URL would be treated as having a non‑default port, causing duplicate rows for the same logical document and violating the deduplication contract.

  ```python
  ("https://example.com:0443/x", "https://example.com/x"),  # equivalent digit spelling
  ("https://[2001:DB8::1]:443/A", "https://[2001:db8::1]/A"),  # IPv6 + default port
  ```

  The absence of a test for the IPv6‑leading‑zero variant suggests the edge case is unhandled.
