## FINDINGS
- **[severity: high] Store logging may leak credentials and secret tokens** – The helper `_log_ref` in **`mira-crawler/ingest/store.py`** (added around line 13) constructs a log reference by extracting the URL’s `netloc` via `urlsplit`. The `netloc` includes the *userinfo* component (`username:password@host`), so any source URL that carries embedded credentials or tokens (e.g., `https://user:pass@example.com/doc.pdf`) will have those secrets emitted to the application log:

  ```python
  origin = urlsplit(url).netloc or "<no host>"
  return f"{origin} sha256:{hashlib.sha256(url.encode('utf-8')).hexdigest()[:12]}"
  ```

  This log entry is used in `insert_chunk` when a write is refused:

  ```python
  logger.warning(
      "Refusing knowledge_entries write for %s — %s",
      _log_ref(source_url),
      prov_reason,
  )
  ```

  Consequently, **operator logs can contain raw authentication material**, violating secret‑handling policies and exposing credentials to anyone with log access.  
  Moreover, the function also logs a **SHA‑256 hash of the full URL**. While the hash is not reversible, it can be brute‑forced for low‑entropy secrets (e.g., short API tokens), providing another side‑channel for secret discovery.

- **[severity: medium] PR‑kind is determined before evidence‑artifact removal, causing possible mis‑classification** – In **`tools/gate7_review.py`**, the PR kind (`code`, `documentation`, `mixed`) is computed **before** the evidence‑artifact exclusion step (`drop_evidence_artifacts`). Evidence artifacts (e.g., `.log` files under `units/evidence/`) are classified as documentation by `_DOC_SUFFIXES`. If a scoped (`--paths`) review contains only evidence artifacts, the kind calculation may label the PR as “documentation” (or “mixed”) even though those artifacts are later stripped from the diff and never reviewed. This can lead to misleading “decision‑point reminders” and inaccurate audit records.  
  Relevant lines: kind computation around line 425 (`kind = pr_kind(scoped_paths(...))`) followed by evidence removal around line 442 (`diff, artifacts = drop_evidence_artifacts(diff)`).
