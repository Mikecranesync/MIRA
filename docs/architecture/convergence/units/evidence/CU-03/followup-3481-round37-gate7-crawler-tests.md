  ```python
  gap = r"(?:\s|/\*.*?\*/|--[^\n]*\n)"  # whitespace or a SQL comment
  re.finditer(

  ```  
  Because the pattern stops at the first `\bWHERE\b`, an UPDATE such as  

  will truncate the captured group before `is_private = TRUE`, causing the scanner to miss the assignment. Consequently the test suite may report “no UPDATE assigns `is_private`” while a real production query could silently set the privacy flag, violating the privacy‑by‑default contract.
