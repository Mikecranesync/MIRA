- **[severity: high] Documentation of strict verdict/ruling shape is not enforced by the implementation** — `.claude/commands/gate7-review.md:103-119`  
  The added documentation states:

  ```diff
  - **A verdict exists only in the briefed shape.** Fresh reviewer output must contain exactly one `## VERDICT` (PASS or BLOCK alone on the next line), exactly one `## FINDINGS`, exactly one `## NOT REVIEWED`; findings are parsed only from `## FINDINGS`. Fresh adjudication output must contain exactly one `## RULINGS`, and rulings are parsed only from it (exact bijection by stable id, no severity channel). Missing/duplicated/malformed ⇒ UNKNOWN — never PASS or BLOCK. A malformed attempt never waives the requirement for a valid verdict, and **there is no Gate 7 round or attempt cap** — a BLOCK is cleared only by (a) or (b) above, and a lane that has not yet produced a valid shape simply has no verdict yet.
  ```

  However, the corresponding implementation (`tools/gate7_review.py`) is unchanged in this PR and does **not** enforce these strict shape constraints. Existing tests in earlier rounds (e.g., round R, round T) show that malformed outputs with extra sections were previously accepted as PASS or BLOCK, indicating the enforcement is not present. This discrepancy means the documentation is false and could allow malformed reviews to be accepted, violating the intended security posture.

- **[severity: medium] Documentation claims every excluded path is listed in run receipts, but the implementation does not generate such receipts** — `.claude/commands/gate7-review.md:104-108`  
  The new policy adds:

  ```diff
  - **Evidence artifacts are excluded by default — and receipted.** Preserved raw reviewer/adjudicator outputs and lane logs under `docs/architecture/convergence/units/evidence/` (documentation/log suffixes only, keyed on both sides of a rename) are dropped from the reviewed diff. `README.md` and `*rebuttal*` files stay in review; executable or structured files under that directory never hide there. **Every excluded path is listed in the run receipts.**
  ```

  The PR does not modify `tools/gate7_review.py` to emit a receipt listing each excluded artifact path. Existing test `test_preserved_evidence_artifacts_are_dropped_from_the_reviewed_diff_and_receipted` checks for receipt output, but without code changes the receipt generation remains unchanged from prior behavior, which only reports a summary count, not a full list of paths. Consequently, the claim that “every excluded path is listed” is inaccurate. This false claim may mislead reviewers into believing they have full visibility of what was omitted, while the actual implementation does not provide that detail.
