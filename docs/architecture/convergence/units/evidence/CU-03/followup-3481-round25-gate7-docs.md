## FINDINGS
- **[severity: high] Duplicate storage due to lack of default‑port normalization** — `mira-crawler/ingest/store.py`  
  The function `canonical_source_url` only lower‑cases the scheme and host, explicitly preserving the port:  
  ```python
  """Lower-case ONLY the scheme and the host of ``url``; every other byte —
  userinfo, port, path, query, fragment — is preserved exactly as given.
  ```
  Because the port is left unchanged, URLs that differ only by the presence or omission of the default port (e.g., `http://example.com` vs `http://example.com:80`) will be stored as distinct rows. If one row is marked private and the other public, a private document can become visible through the public row, violating tenant‑scoped privacy guarantees.

- **[severity: high] Duplicate storage due to case‑sensitive percent‑encoding** — `mira-crawler/ingest/store.py`  
  The same docstring makes it clear that percent‑encoding is not normalised:  
  ```python
  """Lower-case ONLY the scheme and the host of ``url``; every other byte —
  userinfo, port, path, query, fragment — is preserved exactly as given.
  ```
  Consequently, URLs that differ only by the case of percent‑escaped characters (e.g., `%7a` vs `%7A`) are treated as distinct keys, allowing duplicate rows with potentially different `is_private` flags. This can lead to a private ingest being shadowed by a public duplicate.

- **[severity: high] Evidence‑artifact exclusion may bypass review on renamed files** — `tools/gate7_review.py`  
  The implementation of `drop_evidence_artifacts` parses diff headers but only checks the *new* (`b/`) path when deciding whether to drop a file:  
  ```python
  def drop_evidence_artifacts(diff: str) -> tuple[str, list[str]]:
      # Identify all files under units/evidence/ that are considered evidence artifacts.
      # We parse diff header lines for file paths.
      # For each file path, if is_evidence_artifact returns True, we drop that part from diff.
  ```
  The logic does not explicitly handle rename headers (`rename from …` / `rename to …`) on the *old* side, meaning an attacker could place a malicious script under `units/evidence/`, rename it to a non‑evidence path in the same commit, and the artifact would not be dropped because the check only sees the new path. This opens a route for code to be hidden from the lane while still being part of the PR.
