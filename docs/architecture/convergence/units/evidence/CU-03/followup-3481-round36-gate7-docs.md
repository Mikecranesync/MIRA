  This regex removes only hyphens, underscores, dots and whitespace. A malicious URL can therefore hide a credential‑family name by inserting a ‘+’, e.g. `https://example.com?api+key=SECRET`, which will be transformed to `api+key` (the ‘+’ remains) and will not match any of the listed credential families (`api_key`, `apikey`, `access_token`, etc.). As a result, the gate will treat the URL as ordinary and allow it to be stored, potentially persisting credentials in the database. The existing test suite does not cover the ‘+’ separator, leaving this vector unchecked.
