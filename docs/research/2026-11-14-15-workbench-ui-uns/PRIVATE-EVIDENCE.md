# Private evidence retained locally

The public collection preserves the written findings, plans, sources and generated mockups. It does not publish raw tablet captures or browser-response/DOM JSON from the signed-in workspace. Those files expose private workspace navigation and record identities, and the original tablet receipt explicitly required them to remain private until sanitized.

The original evidence remains on CHARLIE in `Documents/Codex/2026-11-14/workbench-pilot/tablet-first-proof/`. References to filenames such as `19-answer-result.png`, `41-final-handoff.png`, `version-before.json` and `stale-scope-retry.json` in the public receipt identify that private evidence set; they are not missing public attachments or newly rerun checks. Private project deep links and the notebook, conversation and component identifiers are omitted from the public receipt.

The published nine PNGs are generated design illustrations previously inspected for unrelated account/project details. They remain byte-identical to their source artifacts. In particular, the comparison board's left side is an illustrated reconstruction, not raw tablet evidence.

Local skill backups, installed home-directory skills, other agents' source checkouts, review logs, dependencies and private memory notes are outside the research publication. The handoff installation receipt is included, while the staged skill implementation remains in its existing branch.

Repository source references point to the publication base commit, or to the archived files in this collection. Other local paths are historical provenance pointers, not claims that a file is available to every GitHub reader. Requests to open private evidence should go to its existing owner; no new access grant is implied by this archive.
