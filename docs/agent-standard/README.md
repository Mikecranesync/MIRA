# FactoryLM Agent Standardization Pack

This pack is designed to standardize **behavior, context, task execution, and evidence** across FactoryLM nodes and coding-agent providers while preserving legitimate machine-specific roles.

Start with:

1. `FLEET_STANDARD.md`
2. `rollout.md`
3. the node-specific runbook
4. the provider-specific compliance adapter

The target repository layout is documented in `rollout.md`.
