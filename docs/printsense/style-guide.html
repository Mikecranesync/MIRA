Landing page style guide

A convincing, credibility-first design system for the hook products — grounded in a teardown of 25 industry landing pages. The centerpiece is the one thing competitors can't fake: a real MIRA answer citing a real manual.

v1.0 · scope: printsense + drivecommander hooks, aligned to factorylm.com · July 2026
01 — Principles

Five rules everything else obeys

These come straight from what the best pages in your space actually do. When a design decision is unclear, the answer is whichever option serves these five.

01

Show the output, don't describe it

Linear and Vercel put the real product on screen above the fold. Your product's output is a cited answer. Lead with it — no stock illustrations, ever.

02

Credibility beats cleverness

Technical buyers punish hype. Evidence, real fault codes, real manual sections, and honest limits convert them. Keep FactoryLM's "no AI hype" voice.

03

One page, one job

The hook page has exactly one goal: claim 5 free reads. Every section either builds trust toward that or gets cut.

04

Motion clarifies, never decorates

Subtle scan-lines, scroll reveals, a citation that expands. Motion that explains "how it's grounded." Nothing that slows the page.

05

Trust is a color

Green = grounded/pass. Amber = held/verify. Red = stop/fault. Never decorative. The palette itself tells the safety story.

03 — The centerpiece component

The Cited Answer Card

This is the whole guide in one object. A real technician question, MIRA's grounded answer, and the manual sections it's built on — shown, not claimed. It leads the hero and repeats as social proof. Everything else is scaffolding around this.

🔧
"PowerFlex 755 is tripping F5 at about 1,200 RPM overnight. What do I check?"
Asset POW-755-A12 · Line 3 · sent via Telegram 02:14
MMIRA grounded answer
F5 on this drive is a DC bus undervoltage fault. The last 7 days show 4 trips in the same RPM band, all overnight — a pattern consistent with sagging bus voltage under load, not a random fault. The manual's fault-recovery section points to the DC bus capacitor bank as the first check, and your own PM history flags it: the 2024-12-14 inspection noted bulging on capacitor 3. Start there before touching drive parameters.
📄 PowerFlex 755 Manual · §6.2 Fault F5 🗂️ Fault history · POW-755-A12 · 7 d 🛠️ PM record · 2024-12-14
◆ GROUNDED 5/5 3 sources · 0 unsupported claims · read-only

Anatomy & rules

Question headerrequiredReal technician phrasing (fault code + symptom + asset). Never a marketing question. Shows the channel it came in on.
Grounded claimshighlightEvery fact that traces to a source is cyan-highlighted. If it isn't highlighted, it isn't cited — and shouldn't be in the answer.
Citation chipsrequiredOne chip per source: manual §, fault history, PM/work order, PLC tag. This is the Harvey/Glean/Perplexity move. Chips are the proof.
Grounding badgerequiredThe 1–5 groundedness score + source count + "read-only." Turns the trust claim into a number.
Safety variantconditionalWhen a safety keyword fires, the card flips to a red ⚠ STOP header ("MIRA escalates, it never acts"). Reinforces the honest-limits brand.

Examples are representative of MIRA's real output shape and grounded on OEM documentation of the type FactoryLM indexes; swap in verified §/page numbers from a specific manual before any answer is presented as a factual claim.

The one hard rule

cyan = action & grounded evidence green = pass / ok amber = held / verify red = stop / fault

State colors are NEVER decorative. A green thing is a passing thing. This mirrors the FactoryLM UI token doctrine (muted normal; color = state only) so the hook and the platform feel like one company.

05 — Typography

Two families. Oversized display, mono for proof.

A clean grotesk sans for everything human (Inter / system stack), and a monospace for anything that signals "machine truth" — fault codes, citations, tags, scores. The mono is a trust device: it makes evidence look like evidence.

Display / H1 · 800 · -1.5Trust the graph
H2 · 800 · -0.8Read any print
H3 · 700How it works
Body · 400/600 · 17pxSend a photo of a drawing; get a typed, evidence-backed graph.
Small / muted · 14pxNo card. 5 free interpretations, then paid.

Max two families. Mono is reserved — if it isn't machine data, it isn't mono. Oversized headlines (2026 trend) but kept legible; kinetic/scroll type only on the hero.

07 — Page blueprint

The section order that converts

Sequenced so the page delivers value even if the visitor never scrolls, then stacks proof before the ask. This is the recommended order for the PrintSense hook page.

Hero = a live Cited Answer Card + one-line promise + "5 free reads" CTA

Show the output first. Headline states the outcome, not the feature. Interactive if possible (type a question).

Proof strip — 68k chunks, manufacturer logos, 0 misreads

Instant credibility wall. Real numbers, real OEM names.

The thesis — good prose ≠ a trustworthy graph

The ATV340 81/B-with-P0-errors story. Your differentiator, stated plainly.

Manual Q&A gallery — 3–4 more Cited Answer Cards, different manufacturers

The convincing core. Rotate AB / Siemens / Schneider so buyers see their own gear answered.

How it works — photo → read → gate → verdict (4 steps)

Demystify. Reinforce read-only + deterministic gate.

Generic-AI vs PrintSense comparison

The same question, two answers. Sharpens why grounding matters.

Pricing — Free (5) → Pro → Team

Answer price before they ask (Stripe move). Team tier upsell = export to FactoryLM namespace.

Ecosystem ladder — PrintSense → MIRA → FactoryLM

"You are here." Show the platform without competing for the free-tool conversion.

Final CTA — email capture to unlock 5 reads

Single field. Restate: no card, read-only, nothing writes back.

08 — Motion & voice

How it moves, how it talks

Motion — do

  • Scroll-reveal sections (subtle fade + rise, ~600ms)
  • A scan-line sweeping the print in the hero
  • Citation chips that expand to show the source on hover
  • Counters that tick up on stats when in view
  • Respect prefers-reduced-motion

Motion — don't

  • Auto-playing carousels or parallax that fights scroll
  • Anything that delays the hero paint
  • Decorative floating blobs / particles
  • Motion on the safety STOP card — it must feel instant & sober

Voice

Say it like this

  • "Get a graph you can actually trust."
  • "An A-grade read, correctly held for review."
  • "MIRA escalates. It never acts."
  • "Nothing writes back to your systems — ever."
  • Plain, technician-first, quantified.

Never this

  • "Revolutionary AI-powered synergy platform."
  • Vague superlatives with no number behind them.
  • Over-promising autonomy or control.
  • Corporate hedging. Keep FactoryLM's "no AI hype" spine.
09 — In one line

Show a real answer, cite a real manual, and let honesty do the selling.

Everything in this guide serves that sentence. The Cited Answer Card is the product; the rest is a frame that gets a skeptical technician to trust it in under 60 seconds.
