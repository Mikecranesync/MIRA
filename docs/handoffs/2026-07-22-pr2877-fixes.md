# PR 2877 Fix Handoff

PR #2877 is green, but hold merge until these adversarial review fixes land.

## 1. Validate Tenant Document IDs As UUIDs

Files:

- `factorylm_ai/adapters/printsense.py`
- `factorylm_ai/adapters/drive_commander.py`

Problem: tenant lineage wraps `document_uuid` / `pack_uuid` without validating the value. A 64-char content hash can become `tenant:<id>:document:<hash>`, bypassing the bare-hash guard.

Fix:

- parse tenant IDs with `uuid.UUID(...)`
- canonicalize lineage values with `str(uuid.UUID(value))`
- reject non-UUID values with `ValueError`
- add tests proving 64-hex hashes are rejected for both PrintSense and Drive Commander tenant records

## 2. Require Real Document Lineage For Shared Drive Packs

File:

- `factorylm_ai/adapters/drive_commander.py`

Problem: shared packs fall back from `document_number` to `drive_model`, producing lineage like `automationdirect:gs10`. That can collapse distinct manuals or revisions into one lineage.

Fix:

- require `document_number` or an explicit `manual_id`
- do not use `drive_model` as lineage
- keep `drive_model` only in metadata
- update tests that currently expect `automationdirect:gs10`

## 3. Reject Uppercase Bare Hash Lineage

Files:

- `factorylm_ai/governance/lineage.py`
- `factorylm_ai/adapters/source_candidate.py`
- `tests/factorylm_ai/test_corpus_adapters.py`

Problem: `is_bare_content_hash()` only catches lowercase hex. `document_lineage_key="A" * 64` is currently accepted.

Fix:

- make the bare-hash regex case-insensitive, or normalize before matching
- add a regression test for uppercase 64-hex lineage
- confirm existing lowercase hash tests still pass

## 4. Prevent SimLab Metadata Override

File:

- `factorylm_ai/adapters/mira_simlab.py`

Problem: user-provided `record["metadata"]` is merged after authoritative fields, so it can override `synthetic`, `origin`, or `ident`.

Fix:

- merge user metadata first, then set authoritative keys last
- or store user metadata under `source_metadata`
- add a test proving `synthetic=True`, `origin=<source>`, and `ident=<ident>` cannot be overridden
