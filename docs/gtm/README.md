## Evidence and lifecycle conventions

Every row below inherits **last checked 2026-10-29** unless another check date is
explicitly written. That date means the stated check was performed, not that the
underlying asset or deployment was refreshed. Source dates remain in the row.

- **Verified record/content:** repository file or GitHub body/comment read in this
  pass. A verified report is not independent verification of its claimed result.
- **Metadata verified:** title/location/state returned by the owning service;
  contents, functionality, publication and freshness may still be unverified.
- **Reported only:** supplied inventory or an agent handoff; original asset not
  inspected. Retain the locator and ask its custodian for evidence.
- Lifecycle is separate: **current execution record**, **draft/proposal**,
  **historical/superseded**, **deployment reported**, or **unknown**. A merged PR
  is not automatically deployed; a deployed surface is not automatically accepted.
- Owner means a source-recorded role/session, not a new assignment. **Unassigned**
  means no confirmed accountable maintainer was found. Agent comments posted
  through the owner's GitHub account are still agent reports unless they explicitly
  record an owner decision. A suggested next action is not authorization to execute it.
