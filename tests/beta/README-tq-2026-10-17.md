# The real 2026-10-17 prod-test questions

`tq-2026-10-17.json` holds the technician's **actual words** from the 2026-10-17 production test, exported
read-only on 2026-10-18 from the eval account's `QA-prover-2026-10-17 …` notebooks on `app.factorylm.com`
(`equipment_notebook_turns`). Each entry records the question, the notebook (and its attached manual), the
first date asked, how many times it was asked, and the recorded `answer_status` per ask. **Answers are not
recorded** — this file is the question set, not a truth set.

Why it exists: every fixture written for the overnight-1017 fix set (#4484–#4490) except TQ-29's page label was
a reconstruction of the task description, and that is exactly how the first TQ-29 gap survived a green suite
(the reconstruction passed; the real string returned `false`). Tests that claim to cover a TQ should quote
from here.

ask; they are a signal about the 2026-10-17 build, not a grade of the answer.
