Fault types

From the manual's Fault Types table (page 159): Type 1, Auto-Reset/Run. When A541 [Auto Rstrt Tries] is set above 0, a timer (A542 [Auto Rstrt Delay]) starts, then the drive attempts to reset the fault itself; if the condition is gone, the fault resets and the drive restarts. Type 2, Non-Resettable. "This type of fault may require drive or motor repair, or is caused by wiring or programming errors. The cause of the fault must be corrected before the fault can be cleared." FactoryLM note (our reading of the table, not Rockwell's wording): the manual describes automatic reset only for Type 1 and calls Type 2 Non-Resettable, so do not expect Auto Restart to clear a Type 2 fault.

Type 2 in this list: F003 Power Loss, F012 HW OverCurrent, F015 Load Loss, F033 Auto Rstrt Tries, F038 Phase U to Gnd, F039 Phase V to Gnd, F040 Phase W to Gnd, F041 Phase UV Short, F042 Phase UW Short, F043 Phase VW Short, F064 Drive Overload, F070 Power Unit, F071 DSI Net Loss, F072 Opt Net Loss, F073 EN Net Loss, F080 Autotune Failure, F081 DSI Comm Loss, F082 Opt Comm Loss, F083 EN Comm Loss, F091 Encoder Loss, F094 Function Loss, F100 Parameter Chksum, F101 External Storage, F105 C Connect Err, F106 Incompat C-P, F107 Replaced C-P, F109 Mismatch C-P, F110 Keypad Membrane, F111 Safety Hardware, F114 uC Failure, F122 I/O Board Fail, F125 Flash Update Req, F126 NonRecoverablErr, F127 DSIFlashUpdatReq.

Auto Restart (A541 [Auto Rstrt Tries], A542 [Auto Rstrt Delay]) makes the drive restart itself. Rockwell: "Use caution when enabling this feature, since the drive attempts to issue its own start command based on user selected programming." Equipment damage and/or personal injury may result if these parameters are used in an inappropriate application. "Do not use this function without considering applicable local, national, and international codes, standards, regulations or industry guidelines."

Clearing a fault (steps from manual page 160)

FactoryLM note: lock out per site procedure before working on a faulted drive. Confirm it is safe for the drive and the machine to run before clearing a fault, and confirm no run command is present: clearing can let the drive start.

  1. Press Esc to acknowledge the fault. Check b007 [Fault 1 Code] for the most recent fault.
  2. Address the condition that caused the fault. The cause must be corrected before the fault can be cleared. For a Type 2 fault, do the corrective action listed for that code (pages 161 to 163) before clearing.
  3. Once the cause is corrected, clear the fault: press Stop if P045 [Stop Mode] is set between 0 and 3, cycle drive power, set A551 [Fault Clear] to 1 "Reset Fault" or 2 "Clear Buffer", or cycle a digital input set to 13 "Clear Fault".

Questions

What does PowerFlex 525 fault F004 mean?

F004 is UnderVoltage, a Type 1 fault, listed in the fault table on page 161 of 520-UM001.

How do I clear a PowerFlex 525 fault?

Correct the cause first. Rockwell's manual (page 160) then lists four ways to clear it: press Stop if P045 [Stop Mode] is set between 0 and 3, cycle drive power, set A551 [Fault Clear] to 1 or 2, or cycle a digital input set to 13 Clear Fault.

What is the difference between Type 1 and Type 2 faults?

The manual's Fault Types table (page 159): Type 1 is Auto-Reset/Run. With A541 [Auto Rstrt Tries] above 0, the drive attempts to reset the fault itself after A542 [Auto Rstrt Delay]. Type 2 is Non-Resettable: it may require drive or motor repair, or is caused by wiring or programming errors, and the cause must be corrected before the fault can be cleared. FactoryLM note (our reading of the table, not Rockwell's wording): the manual describes automatic reset only for Type 1 and calls Type 2 Non-Resettable, so do not expect Auto Restart to clear a Type 2 fault. Auto Restart makes the drive start itself; see the Auto Restart caution on this page.

Where is the full PowerFlex 525 fault table?

In Fault Descriptions, pages 161 to 163 of PowerFlex 525 User Manual, Rockwell publication 520-UM001O-EN-E (September 2025). It lists the causes and corrective actions for each fault.
