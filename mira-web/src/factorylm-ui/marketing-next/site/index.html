A few things to know

Before your
first question.

Talk it through with Mike
What do I need to get started?

A MIRA account and an OEM manual or electrical print set for one piece of equipment. Create your account using your verified work email, then add an equipment notebook, attach the PDF and ask a question.

Can I use electrical prints as well as manuals?

Yes. Attach your electrical print set as a PDF and ask about documented component references and drawing notes. Search depends on readable text in the PDF; a drawing made only of lines or an image may not contain enough searchable information. Check the original sheet and see the electrical-print limits.

Is MIRA free for technicians?

Free for technicians. For a plant or enterprise rollout, talk with Mike about your team’s needs.

Do I need to change my CMMS?

MIRA stands alone. CMMS connections are optional add-ons and are not currently available. You can start with a manual or electrical print set.

Can I see the source behind an answer?

MIRA cites the attached document. On desktop, a citation opens the source page. See the current limitations for phone citation viewing and how to check answers safely.
