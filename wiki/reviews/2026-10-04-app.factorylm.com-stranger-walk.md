## What this walk found broken — the public `/quickstart/` demo (filed as #4224)

The anonymous `/quickstart/` try-door works and cites for well-formed queries, but two defects:

- **Defect B (grounding-honesty gap) — the P0, and what this PR fixes.** On `citations:[]`
  the route served a confident, unlabelled answer, breaking the page's own promise "If we
  can't cite a source, we say so." The authenticated notebook already stamps "General
  guidance — not grounded in this machine's documents."; quickstart did not. Surface-
  independent and the higher-leverage fix per Mike.
- **Defect A (short/mnemonic fault-token retrieval miss) — deferred to #3334.** Well-formed
  codes (`F005`→6 cites, `F070`→5) and procedures cite fine; short/mnemonic/malformed tokens
  (`oC`, the page's own malformed `F0004`) return `citations:[]`. This is a production
  retrieval-ranking problem that cannot be verified from a code session (it needs the real
  corpus + the staging gate), so no speculative ranking change was made here.

## What this PR changes (fix/4224-quickstart-ungrounded-honesty)

1. **Honesty floor:** `/api/quickstart/ask` now prepends `QUICKSTART_UNGROUNDED_NOTICE`
   (a plain-text — the page renders `whitespace-pre-wrap`, not markdown — "not grounded in
   an OEM manual" label) when `citations.length === 0 && !isRefusalAnswer(..)`. Mirrors the
   notebook; the explicit refusal is never double-stamped. New helper lives next to
   `isRefusalAnswer` in `manual-rag.ts` (the one citation-hygiene module).
2. **Placeholder:** the demo's own example `F0004` (malformed — the real code is F004/F005)
   → `F005`, a well-formed code empirically verified to cite on this path. Removes the
   self-inflicted zero-citation first impression.
3. Red-first test + two controls (`ungrounded-honesty.test.ts`): cited → no notice; explicit
   refusal → not double-stamped.
